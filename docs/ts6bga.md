# TS-6BGA 開発メモ

出典：[GORRY「TS-6BGA用ソフト開発ページ」](https://gorry.haun.org/ts6bga.html)。取得日：2026-11-18。
ハードウェアはベータ版、ドライバ仕様は1996-06-23時点の記述。製品版・現在の仕様の保証ではない。

## 概要

九十九電機の X680x0 用グラフィック拡張ボード。GD-5434、2 MB DRAM、PCM69 を搭載。
RGB-IN／OUT により本体映像と拡張画面を切り替える。サウンドはマーキュリーユニット互換ではない。

## 表示能力（画面モード）

ページの「TS-6BGAハードウェア仕様」節（ベータ版の仕様と明記）に掲載された解像度・色数。表ではなく箇条書きを整理した。

| 解像度 | 色数 | X68000純正ディスプレイ |
| --- | --- | --- |
| 768×512 | 32768色・1670万色 | 使用可能 |
| 1024×768 | 32768色 | 使用不可能（Windows/Mac用ディスプレイなどを使用） |
| 1280×1024 | 256色 | 使用不可能（同上） |

- 原文注記：「解像度はTS-6BGA掲載のもののみで、設定次第でもっと多様に設定できると思われる」。対応モードの全量ではない。
- 各モードの水平・垂直走査周波数は記載なし。純正ディスプレイで使えるかの区別だけで、周波数は推測しない。
- `TS6BGAG.X` には `_A_MODE`（`$03`）、`_A_G_DISP`（`$22`）などのコール番号があるが、引数・モード番号は「詳しいことはまだ定めていない」（1996-06-23時点）。
- 画面モード設定ツール GAdisp.r v0.03（Gao氏提供、GADISP03.LZH、1996-07-09）がページに掲載されているが、設定できるモードの一覧はない。

## 開発時の入口

| 対象 | ページに記載された仕様 |
| --- | --- |
| VRAM | `$EE0000` または `$EF0000` の64 KB窓。ジャンパで選択 |
| バンク | `$E9E3CF` に9、`$E9E3CE` にオフセットをバイト書き込み |
| PCM データ | `$E9E200.w`、16-bit big-endian、ステレオは L→R、DMA 可 |
| PCM・画面制御 | `$E9E210.w`。未定義ビットの変更を避ける |
| ドライバ | `TS6BGAG.X`。IOCS `$F9`、`d1` に機能番号、`trap #15` |

## 実装前に確認する点

DMASTART が bit 7 と bit 0 の両方に記載され、役割の違いは説明されていない。
発音能力の24 kHz表記とクロック選択表の対応も未解決。推測で補わない。
描画アクセラレータはチップの能力と、当時のドライバ対応を分けて扱う。
製品版、回路、ドライバソース、実機の挙動を追加確認する。
