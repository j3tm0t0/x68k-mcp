# 資料と公開用データの扱い

このプロジェクトは、X68000開発に必要な技術情報を、対象機種・CPU・資料の版と出典を確認しながら利用するためのものです。

リポジトリには、実装、書誌・出典メタデータ、独自の構造化注釈、評価用データを収録します。原本PDF、原本画像、抽出全文、検索DBは同梱しません。

`tables/` は仕様の値・条件などを独自のスキーマに整理したデータです。出典ページ、元PDFのハッシュ、照合方法、適用範囲を保持し、原文とプロジェクト側の注釈を区別します。AIによる照合を人手の校正とは扱いません。

コードのMIT Licenseは、出典資料に対する利用・再配布の許諾を付与するものではありません。各資料やOSSを取り込む場合は、対象ファイルの利用条件、著作権表示、帰属などを確認してください。メーカーやWebで公開されていることだけで、自由な再配布が認められるとは扱いません。

技術的事実と、説明文・図表・コードなどの表現を区別します。出典と範囲の誤り、第三者の表現の混入が疑われる箇所は、該当ファイルと資料の位置を添えてIssueで知らせてください。

ソフトウェアと資料データのライセンスの区別は [NOTICE](../NOTICE.md) を参照してください。
